## Install the CLI {#install-cli}

The SharpNR CLI is the fastest way to scaffold, sync, and manage your workspace from the terminal.

<CodeBlock lang="bash">{`npm install -g @sharpnr/cli`}</CodeBlock>

Confirm the install:

<CodeBlock lang="bash">{`sharpnr --version`}</CodeBlock>

You should see something like `sharpnr/1.4.2 linux-x64 node-v20.11.0`.

## Step-by-step setup {#setup}

<Steps>

<Step number={1} title="Authenticate your account">

Log in from the terminal. This opens a browser tab to complete OAuth — no passwords stored locally.

<CodeBlock lang="bash">{`sharpnr login`}</CodeBlock>

On success you'll see:

<CodeBlock lang="bash">
  {`✓  Authenticated as you@company.com
✓  Workspace: Acme Inc  (slug: acme)`}
</CodeBlock>

<Callout type="info">

Your session token is stored in `~/.sharpnr/credentials.json`. It expires after 30 days of inactivity.

</Callout>

</Step>

<Step number={2} title="Create your workspace">

A workspace is your organization's home inside SharpNR — every product, user, and integration lives under it.

<CodeBlock lang="bash">{`sharpnr workspace create`}</CodeBlock>

You'll be prompted to enter:

- **Display name** — shown across the platform (e.g. `Acme Inc`)
- **Slug** — your unique identifier for API calls and CLI commands (e.g. `acme`)
- **Region** — where your data is stored (`us-east-1`, `eu-west-1`, or `ap-south-1`)

<Callout type="warning">

Your workspace **slug cannot be changed** after creation. Choose something short, lowercase, and recognizable.

</Callout>

</Step>

<Step number={3} title="Initialize your project">

Inside your project directory, run:

<CodeBlock lang="bash">{`sharpnr init`}</CodeBlock>

This scaffolds a `sharpnr.config.ts` at your project root:

<CodeBlock lang="ts" filename="sharpnr.config.ts" variant="file">
{`import { defineConfig } from "@sharpnr/sdk";

export default defineConfig({
  workspace: "acme",
  products: ["iam", "hr", "accounting"],
  region: "us-east-1",
  environment: process.env.NODE_ENV ?? "development",
});`}
</CodeBlock>

</Step>

<Step number={4} title="Sync your environment">

Pull your workspace secrets and configuration into a local `.env` file:

<CodeBlock lang="bash">{`sharpnr sync`}</CodeBlock>

This writes `.env.sharpnr` with all required API keys pre-filled and ready to use.

<Callout type="danger">

Add `.env.sharpnr` to your `.gitignore` immediately. It contains workspace-scoped API keys that should never be committed.

</Callout>

</Step>

<Step number={5} title="Connect SharpIAM">

SharpIAM is the identity backbone shared by all other products. Enable it first.

<CodeBlock lang="bash">{`sharpnr iam init`}</CodeBlock>

Then add the provider to your app:

<CodeBlock lang="ts" filename="src/lib/auth.ts" variant="file">
{`import { SharpIAM } from "@sharpnr/iam";

export const auth = new SharpIAM({
  workspace: process.env.SHARPNR_WORKSPACE_SLUG!,
  secret: process.env.SHARPNR_IAM_SECRET!,
});`}
</CodeBlock>

</Step>

<Step number={6} title="Invite your team">

Add team members and assign roles directly from the CLI or the dashboard.

<CodeBlock lang="bash">
  {`sharpnr team invite --email colleague@company.com --role member`}
</CodeBlock>

Available roles: `owner`, `admin`, `member`, `viewer`

<Callout type="tip">

Bulk-invite by passing comma-separated emails: `--email a@co.com,b@co.com`

</Callout>

</Step>

<Step number={7} title="Run a health check">

Verify everything is connected:

<CodeBlock lang="bash">{`sharpnr status`}</CodeBlock>

<CodeBlock lang="bash">
  {`✓  Workspace:    acme  [us-east-1]
✓  SharpIAM:     connected  (3 users)
✓  Sharp-HR:     connected
✓  Accounting:   connected
✓  API latency:  42ms
●  All systems operational`}
</CodeBlock>

</Step>

</Steps>
