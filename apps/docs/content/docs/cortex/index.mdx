## What is Cortex?

Cortex is the centralized IT administration and access management application for the Sharp platform. It gives IT teams a single control plane to securely manage infrastructure, users, devices, permissions, and organizational resources across every Sharp app.

Where [Orchestrator](/orchestrator) controls *which apps and services* run, Cortex controls *who and what can access the resources* behind them — databases, APIs, secrets, and infrastructure.

**App:** [cortex.sharpnr.com](https://cortex.sharpnr.com)

## What can you do with Cortex?

| Capability                     | Description                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------- |
| Role-Based Access Control      | Define roles and grant permissions over platform resources                   |
| Silo Database Access           | Grant Read, Write, or Admin access to [Silo](/silo) databases                |
| Resource Permissions           | Manage permissions on organizational resources across the platform           |
| API Keys & Service Accounts    | Create and manage credentials for programmatic access                        |
| Secrets & Credentials          | Store and manage secrets securely                                            |
| Infrastructure Access          | Control access to the infrastructure powering your organization              |
| Audit Logs                     | Track every access event and administrative activity                         |
| Security Policies              | Define and enforce security and compliance policies                          |
| Multi-Organization Administration | Administer IT controls across multiple organizations                      |

## Coming soon

Cortex is expanding into full IT management:

- **Device Management** — enroll and manage organizational devices
- **Endpoint Security** — protect the devices that access the platform
- **Asset Inventory** — track IT assets across the organization
- **Policy Enforcement & Approval Workflows** — require approvals before sensitive access is granted
