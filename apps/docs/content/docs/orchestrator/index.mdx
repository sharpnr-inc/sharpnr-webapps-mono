## What is Orchestrator?

Orchestrator is the administration application for the Sharp platform and the heart of the **Organization Control Layer (Layer 2)** in the Sharpnr architecture. Every Sharp application — from Sharp-Hospitality to Sharp-Accounting to Cables — is provisioned and managed through Orchestrator.

It provides a unified interface for platform administrators to monitor, control, configure, and orchestrate every Sharp service from a single dashboard, while giving stakeholders a view of the whole organization.

**App:** [orchestrator.sharpnr.com](https://orchestrator.sharpnr.com)

## What can you do with Orchestrator?

| Capability                 | Description                                                                     |
| -------------------------- | ------------------------------------------------------------------------------- |
| Platform Administration    | One dashboard to administer the entire Sharpnr ecosystem                        |
| App Provisioning           | Enable or disable Sharp applications per company                                |
| Service Control            | Start, stop, and restart Sharp services                                         |
| Organization Management    | Manage companies, branches, and legal entities from one place                   |
| Health & Monitoring        | Service health, status, logs, diagnostics, and resource usage                   |
| Workflows & Automation     | Orchestrate workflows across all connected services                             |
| Access & Security          | Role-based administrative access, user sessions, and audit logs                 |

## Why Orchestrator?

Sharpnr is not a single product — it is a modular ecosystem of connected applications. Organizations enable only the apps they need, and every app works both independently and as part of the unified platform. That flexibility needs a control plane:

- **One place to manage everything** — instead of configuring each app separately, administrators control the whole ecosystem from Orchestrator.
- **Per-company control** — in multi-company organizations, each company can run a different set of apps. A hotel company can run Sharp-Hospitality while a sister clinic runs Lifco, all under one organization.
- **Stakeholder visibility** — owners and stakeholders get a whole-organization view without needing to log into each individual app.
- **Enterprise-grade governance** — every administrative action is captured in audit logs, and administrative access itself is role-based.
