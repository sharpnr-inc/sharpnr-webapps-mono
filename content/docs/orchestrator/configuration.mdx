Orchestrator centralizes the configuration of the Sharp platform — from per-app settings to cross-app workflows and external integrations.

## Platform configuration management

Configure platform-wide and per-company settings from one place:

- **Industry app configuration** — set up industry-specific apps such as [Sharp-Hospitality](/hospitality-sector/sharp-hospitality), which supports highly configurable workflows (shared kitchens, shared menus, routing menu items to different kitchens, and more).
- **Core service configuration** — manage settings for the core services each company has enabled.
- **Per-company overrides** — companies within one organization can be configured differently while staying under central administration.

## Workflow & automation management

Sharpnr's apps are integrated out of the box, and Orchestrator is where those cross-app workflows are managed:

- Orchestrate how apps communicate and interact across the platform.
- Control automatic flows such as [Sharp-Hospitality](/hospitality-sector/sharp-hospitality) posting journal entries to [Sharp-Accounting](/sharp-accounting), or purchase-to-inventory accounting.
- Manage approval workflows that span services.

## API & integration management

Orchestrator manages the platform's API surface and integrations:

- **API management** — the Sharp platform is API-first; Orchestrator is where API access for your organization is administered.
- **Integrations** — manage connections between Sharp services and with external systems.
- **Credentials** — API keys, service accounts, and secrets are managed through [Cortex](/cortex), the IT controls layer, under Orchestrator's central administration.
