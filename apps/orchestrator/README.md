# 🚀 Sharpnr Frontend (FE)

The **Sharpnr Frontend** is a modern, high-performance web application designed to provide a smooth and intuitive user experience.  
It serves as the client-side interface for the **Sharpnr** platform, built using cutting-edge web technologies for scalability, maintainability, and speed.

---

## 🧠 Overview

This repository contains the **frontend codebase** for **Sharpnr**, featuring a modular architecture, reusable UI components, and seamless integration with backend APIs.

---

## ⚙️ About the Stack

- **Node.js version:** `v22.17.0`  
- **npm version:** `10.9.2`

Ensure you have the correct versions installed before running the project to prevent compatibility issues.
