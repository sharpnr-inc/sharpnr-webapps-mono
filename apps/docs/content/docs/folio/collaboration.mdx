Folio is built for working together — the same document, spreadsheet, or whiteboard, edited by the whole team at once.

## Real-time collaboration

Multiple people edit the same content simultaneously and see each other's changes live. No emailing copies, no "who has the latest version" — there is one version, and everyone is in it.

## Comments

Discuss content where it lives: leave comments on documents, spreadsheets, and boards, and resolve them as the work evolves. For longer discussions, share the document into a [Cables](/cables) conversation.

## Version history

Every change is tracked. Version history shows how content evolved and lets teams recover earlier states — edits are never destructive.
