Silo provides the three storage models modern applications need — under one platform, one access model, and one administration surface.

## Object storage

Store and retrieve objects at scale — media, backups, exports, and application data. Object storage is the workhorse behind apps that handle large volumes of files.

## Structured data storage (RDBMS)

Relational database storage for structured, transactional data — the operational records Sharp applications run on. Access to Silo databases is governed through [Cortex](/cortex/access-control), with Read, Write, and Admin grants scoped per database.

## Unstructured file storage

Documents, images, videos, and every other file that doesn't fit rows and columns. Files stored in Silo are available across the platform — the same file a team edits in [Folio](/folio) or shares in [Cables](/cables) lives on Silo underneath.

## One foundation, every app

Sharp applications don't ship their own storage layers — they build on Silo. That is what makes platform-wide capabilities possible: cross-app [data sharing](/silo/data-access-and-sharing), unified [access control](/silo/reliability-and-security), and organization-wide analytics.
