## What is Silo?

Silo is the storage and data platform of the Sharp ecosystem — a unified platform for structured, semi-structured, and unstructured data, designed to serve as the central data foundation for all Sharp applications.

Instead of every app managing its own storage, the whole platform builds on Silo: operational databases, files and media, analytical data, and machine learning datasets all live on one scalable, secure foundation.

**App:** [silo.sharpnr.com](https://silo.sharpnr.com)

## What can you do with Silo?

| Capability               | Description                                                            |
| ------------------------ | ----------------------------------------------------------------------- |
| Storage Services         | Object storage, structured data (RDBMS), and unstructured file storage  |
| Analytics & AI           | Data lake, data warehouse, lakehouse architecture, and ML/AI data storage |
| Data Access & Sharing    | API-first access, high-performance ingestion, and cross-app data sharing |
| Metadata & Schema        | Centralized metadata and schema management                              |
| Reliability & Security   | Backup, replication, encryption, and access control                     |
