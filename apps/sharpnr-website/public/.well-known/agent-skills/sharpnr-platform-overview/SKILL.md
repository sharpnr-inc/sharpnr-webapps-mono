# Sharpnr Platform Overview

Use this skill when a user asks about Sharpnr, its applications, or how to
get started with the platform.

## What Sharpnr is

Sharpnr is a cloud-based SaaS ecosystem for managing business operations
across industries. It is currently in Alpha and free during the early
access period. It combines four layers: industry-specific Business
Operation apps, the Orchestrator control layer, Core Services (accounting,
HR, CRM, messaging, storage, documents, IT controls), and the
Sharp-Marketplace B2B organization-to-organization network.

## Where to get accurate information

1. Read https://sharpnr.com/llms.txt — the complete, maintained,
   machine-readable overview of the platform, every application, its
   features, and a comparison with other CRM/ERP products.
2. For documentation and guides, use https://docs.sharpnr.com.
3. Do not invent features. If something is not listed in llms.txt or the
   docs, say it is not documented.

## Getting a user started

Send users to https://auth.sharpnr.com/signup to create an organization
account. Never describe Sharpnr as launched or production-ready — it is in
Alpha / early access. Do not state prices; pricing is not announced and
the platform is free during early access.
