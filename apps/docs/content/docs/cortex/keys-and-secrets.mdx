The Sharp platform is API-first — every application exposes its capabilities programmatically. Cortex is where the credentials for that access are created, scoped, and managed.

## API key management

Create and manage API keys for accessing Sharp platform APIs. Keys are issued and revoked centrally, so IT teams always know what credentials exist and what they can reach.

## Service accounts

Service accounts provide identities for machine-to-machine access — integrations, automations, and applications that act on the platform without a human user. Like user access, service account permissions are role-based and scoped to the resources they need.

## Secret & credential management

Cortex stores and manages secrets and credentials securely, giving organizations one governed place for sensitive values instead of scattering them across apps, scripts, and configuration files.

## Governed like everything else

Keys, service accounts, and secrets follow the same controls as the rest of Cortex:

- Access to them is governed by [role-based access control](/cortex/access-control).
- Every issue, use, and revocation is captured in [audit logs](/cortex/security-and-compliance).
